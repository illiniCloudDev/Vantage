# Vantage

A sophisticated, dark-themed financial intelligence platform built for tracking personal cash flow and global market sentiment. 

Designed with a focus on eye comfort and professional utility, Vantage provides a "single vantage point" for managing wealth, tracking transactions, analyzing stocks, and monitoring market velocity.

## 🚀 Technical Stack

* **Frontend:** React 19 (Vite)
* **Styling:** Tailwind CSS v4 (Vite-native)
* **Routing:** React Router v7 (Data Router pattern)
* **Icons:** Lucide React
* **State Management:** React Hooks (`useState`, `useContext`)

## ✨ Features

* **Personal Cash Flow:** A calendar-based tracker to monitor spending and budget efficiency.
* **Market Intelligence:** Real-time sentiment analysis and direct integration with market indicators.
* **Alpha Signals:** Advanced tracking (Delta/Theta) for options-focused portfolios.
* **Vantage Agent:** (Planned) An autonomous AI agent for identifying market anomalies.
* **High-Comfort UI:** Custom dark-mode interface designed to reduce eye strain during long-duration analysis.

## 🛠️ Getting Started

### Prerequisites
* Node.js (v18 or higher)
* npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/illiniCloudDev/Vantage.git
2. Install dependencies:
   ```bash
   > cd vantage/frontend
    > npm install
3. Start the development server:
    npm run dev
